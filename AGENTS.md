# Repository instructions

Do not create Git branches using the `codex/` prefix. Use a descriptive prefix such as `feat/`, `fix/`, `docs/`, or `chore/`.

## Agent skills

### Issue tracker

Issues and PRDs are tracked in GitHub Issues. See `docs/agents/issue-tracker.md`.

### Triage labels

Use the default five-role triage vocabulary. See `docs/agents/triage-labels.md`.

### Domain docs

TradeFlow uses a multi-context domain-document layout. See `docs/agents/domain.md`.
